# Git 및 Worktree 작업

- 작업 시작 시 Git 상태·현재 브랜치·Worktree를 확인하고 기존 미커밋·staged 변경과 사용자 작업을 보존한다.
- 가능하면 별도 Worktree와 `feature/` 브랜치에서 수행한다. 원본 프로젝트와 다른 Worktree를 수정하거나 정리하지 않는다.
- Worktree의 Unity 인스턴스는 프로젝트 절대 경로로 확인하고 고정한다. 다른 프로젝트나 원본 Editor로 변경을 전달하지 않는다.
- 커밋은 명시적으로 요청받았을 때만 수행하며 [커밋 스킬](../../.agents/skills/commit/SKILL.md)을 따른다.
- 커밋 전 대상 파일, 메시지, 검증 결과, 현재 브랜치를 간략히 보고한다. 커밋/PR 문구는 저장소의 기존 히스토리와 양식을 따른다.
